# semgrep-lua

Generated lua parser code for opengrep, based on
[tree-sitter-grammars/tree-sitter-lua](https://github.com/tree-sitter-grammars/tree-sitter-lua)
v0.5.0 (Lua 5.1 to 5.5).

The layout is the one of the other `semgrep-*` parser repos:

* `lib/`: the `tree-sitter-lang.lua` library: C parser (`parser.c`,
  `scanner.c`, `bindings.c`) and typed OCaml CST (`CST.ml`, `Parse.ml`,
  `Boilerplate.ml`) generated by `ocaml-tree-sitter`.
* `bin/`: `parse-lua`, prints the CST of a file.
* `fyi/`: the source grammars and the versions used.

Unlike the other parser repos, which are generated from
`ocaml-tree-sitter-semgrep`, this one is generated from the grammars that it
contains, by `scripts/regenerate.sh`:

* `fyi/semgrep-grammars/src/tree-sitter-lua/`: unmodified copy of the
  upstream grammar and external scanner (see `VERSION`).
* `fyi/semgrep-grammars/src/semgrep-lua/grammar.js`: extension of the
  upstream grammar for semgrep patterns.
* `scripts/esm-to-cjs.sh`: converts the upstream ES module grammar to CommonJS,
  so that it can be loaded by the tree-sitter CLI 0.22.6.
* `scripts/regenerate.sh`: regenerates `lib/`, `bin/` and the versions in
  `fyi/`. It requires the tree-sitter CLI 0.22.6 (`TREE_SITTER`), the version
  of the tree-sitter runtime linked by opengrep, and produces tables with
  ABI 14.
* `templates/`: templates of the generated dune files.

Do not edit `lib/` or `bin/` by hand.

## Regenerating

The generator must be built from
[opengrep/ocaml-tree-sitter-core](https://github.com/opengrep/ocaml-tree-sitter-core)
(commit e737fd1 or later, which generates a multicore-friendly `Parse.ml`).
In the opengrep build container (`ocamlpro/ocaml:5.3`, see
`.github/workflows/build-test-core-x86.yml` in opengrep):

```sh
# tree-sitter CLI 0.22.6 (the prebuilt npm binary needs glibc)
apk add cargo nodejs
cargo install --locked tree-sitter-cli --version 0.22.6 --root /opt/tree-sitter
# ocaml-tree-sitter
git clone https://github.com/opengrep/ocaml-tree-sitter-core /opt/otc
(cd /opt/otc && dune build src/gen/bin/Ocaml_tree_sitter_main.exe)

TREE_SITTER=/opt/tree-sitter/bin/tree-sitter \
OCAML_TREE_SITTER=/opt/otc/_build/default/src/gen/bin/Ocaml_tree_sitter_main.exe \
OCAML_TREE_SITTER_VERSION=opengrep/ocaml-tree-sitter-core@$(git -C /opt/otc rev-parse HEAD) \
  scripts/regenerate.sh
```
